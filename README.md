# StaffSync - Modern HR Management System

StaffSync is an end-to-end Human Resource Management platform built with a React frontend and Node.js/Express backend powered by MongoDB Atlas.

## Features
- **Role-Based Access Control**: Separate operational dashboards for HR/Admin and Employees.
- **Workforce Directory**: Centralized view of company staff with management capabilities.
- **Leave Desk**: Full leave request cycle (Apply, Review, Approve, Reject).
- **Company Bulletins**: Real-time company announcements and operational notices.

## Tech Stack
- **Frontend**: React (Vite), Lucide Icons, Modern CSS
- **Backend**: Node.js, Express.js, JSON Web Tokens (JWT), Bcrypt.js
- **Database**: MongoDB Atlas via Mongoose ODM
